# Frontend Design System Profile

1. **Aesthetics & Premium Feel**: Always prioritize high-quality design. Avoid default browser styles and generic "bootstrap-style" layouts. Use curated color palettes (e.g., Tailwind default colors, or carefully tuned HSL values), subtle shadows, and modern typographic scales.
2. **Modern Typography**: Do not use system default fonts for UI unless explicitly requested. Prefer modern sans-serifs (Inter, Roboto, Manrope) and establish a clear heading hierarchy.
3. **Micro-Interactions**: Incorporate subtle hover, focus, and active states for all interactive elements to make the UI feel tactile and alive.
4. **Accessibility (a11y) First**: Ensure proper contrast ratios (WCAG 2.2), semantic HTML (e.g., `<button>` for actions, `<a>` for navigation), and keyboard navigability.
5. **Responsive by Default**: Always assume the design needs to work across mobile, tablet, and desktop breakpoints.
